# 01. 플랫폼 운영 총괄 관리자 실무 매뉴얼 (`role_admin`)

- **대상 역할**: 플랫폼 최고관리자 (`role_admin` / `ROLE_ADMIN`)
- **기본 접속 계정**: `admin` / `123456` (김도현 총괄관리자, `KKUMZ-HQ`)
- **주요 관제 메뉴**: `대시보드`(`/dashboard/analysis`), `창업 기획서`(`작품관리`/`세계관`/`캐릭터`, `/studio/ideas`), `AI 생성 규칙`(`/studio/prompts`), `사이트 목록`(`에피소드`/`크리에이터정산`/`구독플랜`, `/deployment/sites`), `빌드 로그`(`/deployment/builds`), `API 키`(`/deployment/api-keys`), `프로젝트·팀원`(`퀘스트`/`배지관리`, `/community/projects`), `시스템 환경설정`(`환경설정`, `/system/config`), `프롬프트`(`/system/prompt`), `공통 코드`(`/system/dict`)

---

## 1. 플랫폼 운영 총괄 관리자 일일 점검 루틴

1. **전사 스튜디오 생성 및 멀티사이트 가동 현황 점검 (`대시보드` `/dashboard/analysis`)**:
   - `GET /api/v1/kkumz/stats`로 집계되는 누적 창업 기획서·작품 수, 라이브 가동 중인 멀티사이트(`ACTIVE`) 수, 샌드박스 빌드 성공률, 미처리 커뮤니티 신고(`PENDING`) 건수를 확인합니다.
2. **작품·세계관·캐릭터·명세서 카탈로그 검수 (`창업 기획서` `/studio/ideas`)**:
   - 크리에이터가 생성한 아이디어(`kkumz_idea`), AI 브랜드 네이밍 8종(`kkumz_name_suggestion`), 벡터 SVG 로고 6종(`kkumz_logo_suggestion`), 마크다운 명세서 버전 이력(`kkumz_idea_version`)을 `IdeaDetailModal.vue`에서 상세 열람합니다.
3. **크리에이터 수익 정산·구독플랜·SyncShop/SyncCMS 브릿지 관제 (`사이트 목록` `/deployment/sites`, `API 키` `/deployment/api-keys`)**:
   - 각 멀티사이트에 매핑된 `shop_site_id`(`SyncShop` 상품·주문·정산 원장) 및 `cms_site_id`(`SyncCMS` 콘텐츠·예약폼 원장) 연동 상태와 정기구독 플랜(`SHOP_SUBSCRIPTION_TIERS`), 리워드 혜택(`WELCOME_COUPON`, `CREATOR_POINT`, `GIFT_VOUCHER`), API 액세스키(`kkumz_api_access_key`) 호출량을 모니터링합니다.
4. **무중단 동적 환경설정(`/system/config`) 및 AI 프롬프트(`/system/prompt`) 거버넌스**:
   - 서버 재기동 없이 `SystemConfigHolder`(`sys_config`)와 `SystemPromptHolder`(`sys_prompt_template`, `sys_prompt_history`)를 통해 AI 추론 모델, 외부 서비스 연동 URL, 서킷브레이커 쿨다운 및 단계별 프롬프트를 제어합니다.

## 2. 작품·에피소드·멀티사이트 카탈로그 및 샌드박스 빌드 관제

### 2.1 창업 기획서 및 작품·세계관 관리 (`/studio/ideas`)
1. 좌측 메뉴 **[AI 스튜디오 > 창업 기획서]**(`/studio/ideas`)로 이동합니다.
2. 사이트 유형(`COMMERCE`: 쇼핑몰 스토어, `CMS_SITE`: 브랜드·커뮤니티 웹, `HYBRID`: 매거진+스토어 복합), 진행 단계(`Step 1` ~ `Step 6`), 상태(`DRAFT`, `SPEC_READY`, `DEPLOYED`)로 검색합니다.
3. 행 액션의 **[상세]**를 클릭하여 `IdeaDetailModal.vue`를 열면 확정된 브랜드 슬러그, SVG 로고 미리보기, 5대 디자인 토큰(`primary`, `secondary`, `accent`, `surface`, `radius`), 활성화된 52종 기능 카탈로그 코드(`enabled_features_json`) 및 마크다운 기능명세서 전문을 확인할 수 있습니다.

### 2.2 멀티사이트·에피소드 배포 및 크리에이터 정산·구독플랜 연동 (`/deployment/sites`, `/deployment/api-keys`)
1. **[사이트·배포 > 사이트 목록]**(`/deployment/sites`)에서 라이브 배포된 멀티사이트(`/s/{site_slug}`)의 배포 모드(`DYNAMIC_SDUI` 또는 `CUSTOM_BUNDLE`), 활성 버전(`active_version`), 공개 배포 버전(`published_version`), SyncShop/SyncCMS 테넌트 ID 매핑 상태를 확인합니다.
2. **[사이트·배포 > 빌드 로그]**(`/deployment/builds`)에서 WebIDE 커스텀 번들 빌드 잡(`kkumz_build_job`)의 소요 시간(`duration_ms`), 성공/실패 여부, AI 자동 코드 패치(`ai_patch_applied`) 적용 내역을 `BuildLogModal.vue`로 감사할 수 있습니다.
3. **[사이트·배포 > API 키]**(`/deployment/api-keys`)에서 `OUTBOUND`(`SYNC_CMS`, `SYNC_SHOP`) 및 `INBOUND`(`SYNC_VERSE`, `EXTERNAL_PARTNER`) 인증키의 분당 호출 한도(`rate_limit_rpm`)와 누적 호출 수(`call_count`)를 관리하고 키 회전(Rotation)을 수행합니다.

### 2.3 퀘스트·배지·리워드 경제 및 공통 코드 관리 (`/community/projects`, `/system/dict`)
- **[커뮤니티 > 프로젝트·팀원]**(`/community/projects`)에서 우수 작품·사이트를 쇼케이스 추천(`is_featured = true`)으로 큐레이션하고, 크리에이터 활동 배지(`author_role_badge`: 메이커, 헤드로스터, 크루장 등)와 팀빌딩 매칭을 관리합니다.
- **[환경 설정 > 공통 코드]**(`/system/dict`)에서 `kkumz_reward_type`(`WELCOME_COUPON`, `CREATOR_POINT`, `GIFT_VOUCHER`), `kkumz_feature_category`(8대 기능 분류), `kkumz_campaign_status` 등 플랫폼 경제·배지·퀘스트 기준 코드를 동적으로 관리합니다.

### 3.2 AI 프롬프트 이중 거버넌스 (`/system/prompt` 및 `/studio/prompts`)
1. **전사 표준 프롬프트 버전 관리 (`/system/prompt` — `sys_prompt_template`, `sys_prompt_history`)**:
   - `SystemPromptHolder`와 연동되어 프롬프트 코드별 시스템 프롬프트, 유저 프롬프트 템플릿, 변수 JSON 스키마(`variables_schema`), 출력 스키마(`output_schema`), 온도(`temperature`)를 수정하고 `sys_prompt_history`로 버전 비교 및 즉시 롤백을 수행합니다.
2. **스튜디오 도메인 프롬프트 및 금지어 필터 관리 (`/studio/prompts` — `kkumz_ai_prompt_template`)**:
   - 8대 스튜디오 생성 단계(`BRAND_NAMING_8X`, `VECTOR_SVG_LOGO_6X`, `FRS_SPEC_MARKDOWN`, `WEBIDE_AI_BUILD_FIXER`, `SITE_CONCIERGE_CHAT`, `STUDIO_CHAT_REFINE`, `KKUMZ_INTENT_ADVISOR_V1`, `KKUMZ_SITE_PROVISION_V1`)의 프롬프트와 금지어 배열(`forbidden_words_json`)을 `PromptModal.vue`에서 실시간 튜닝합니다.
